নাম, জমা টাকা বা মিলের সংখ্যা সরাসরি এডিট করতে পারবেন। ক্যালকুলেশন সাথে সাথে আপডেট হবে।

সবুজ = ফেরত পাবে (Refund) লাল = জমা দিতে হবে (Due)
# সদস্যের নাম (Member) জমা (Deposit) মিল সংখ্যা (Meal) মিল রেট (Rate) মিল খরচ (Total Cost) ব্যালেন্স (TC - Deposit) স্ট্যাটাস অ্যাকশন
হিসাবের নিয়মাবলী (Calculation Logic)

1. মিল রেট (Meal Rate) = মোট বাজার খরচ ÷ মোট মিল সংখ্যা

2. মিল খরচ (Total Cost) = মেম্বারের মিল সংখ্যা × মিল রেট

3. TC - Deposit: মান ধনাত্মক (+) হলে মেসকে বকেয়া দিতে হবে (Due), মান ঋণাত্মক (-) হলে মেম্বার মেস থেকে অতিরিক্ত টাকা ফেরত পাবে (Refund)।

Google Sheets লাইভ সিঙ্ক সেটআপ

আপনার গুগল শিটের Apps Script Deploy করে প্রাপ্ত Web App URL-টি এখানে দিন।

কিভাবে ৩ মিনিটে কানেক্ট করবেন?

  1. আপনার Google Sheet ওপেন করে Extensions > Apps Script এ যান।
  2. সেখানে থাকা কোড মুছে নিচের স্ক্রিপ্টটি পেস্ট করে সেভ করুন:
function doGet() {
  const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  const rows = sheet.getDataRange().getValues();
  return ContentService.createTextOutput(JSON.stringify({ data: rows }))
    .setMimeType(ContentService.MimeType.JSON);
}

function doPost(e) {
  try {
    const payload = JSON.parse(e.postData.contents);
    const sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    sheet.clearContents();
    sheet.appendRow(["DEPOSIT", "Amount", "Meal", "Meal Rate", "Total Cost", "TC-Amount"]);
    payload.members.forEach(function(m) {
      sheet.appendRow([m.name, m.deposit, m.meal, payload.mealRate, (m.meal * payload.mealRate), ((m.meal * payload.mealRate) - m.deposit)]);
    });
    sheet.appendRow(["Total", payload.totalDeposit, payload.totalMeals, payload.mealRate, payload.totalExpense, 0]);
    return ContentService.createTextOutput(JSON.stringify({ status: "success" })).setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService.createTextOutput(JSON.stringify({ status: "error", message: err.toString() })).setMimeType(ContentService.MimeType.JSON);
  }
}
  1. উপরের নীল Deploy > New deployment এ ক্লিক করুন।
  2. Select type-এ Web app দিন, Who has access: Anyone সিলেক্ট করুন।
  3. Deploy দিলে যে Web App URL পাবেন, তা কপি করে উপরের বক্সে পেস্ট করে সেভ করুন।
